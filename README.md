# 🌌 NyxOS

**NyxOS** is an experimental simulated mobile operating system built completely in **Swift** and **SwiftUI** for iPadOS and iOS. It brings a full desktop/operating-system experience to mobile devices, featuring virtual execution environments, command-line interfaces, custom tweak management, and integrated AI capabilities.

---

## ✨ Features

- 📱 **Simulated Mobile OS Environment**: A smooth windowing and desktop-style interactive layer built with pure SwiftUI.
- 🐚 **Virtual Terminal & CLI**: Integrated command-line environment for running custom terminal commands and executables inside the sandbox.
- ⚙️ **Modular Configuration Architecture**: Flexible configuration management driven by robust `.plist` and entitlement structures.
- 🤖 **AI Assistant Integration**: Built-in intelligent assistant powered by next-gen LLM APIs to handle system-level queries and automation tasks.

🚀 Getting Started
Prerequisites
 Device / Simulator: iPadOS 16.0+ or iOS 16.0+
 Development Tooling: Nyxian, Swift Playgrounds, or Xcode
Installation

1. Clone the repository:
git clone [https://github.com/Hamouddabest/NYXos.git](https://github.com/Hamouddabest/NYXos.git)

2. Open the project folder in your Swift development app on iPadOS or Xcode on macO

3. Build and run ⁠NYXosApp.swift⁠.
